#Helix DSDS Agent
A GitHub Copilot Agent for VS Code that generates and maintains Design System Documentation Specification (DSDS) YAML files using Cancer Research UK's Helix design system documentation.

Source of truth:

- Helix (Zeroheight)

Output:

- DSDS v0.23.1 YAML

Primary features:

- Create component documentation
- Update component documentation
- Validation
- Auditing
- Changelog generation
- Bulk synchronization
